##  SQL Analytics

Advanced SQL for analysis: CTEs, window functions, ranking, running totals, moving averages, customer lifetime value, retention and cohort analysis, complex joins, and query optimization.

<details>
<summary><b>Ranking & running totals</b></summary>

```sql
WITH monthly_sales AS (
    SELECT
        DATE_TRUNC('month', order_date) AS month,
        product_id,
        SUM(revenue)                    AS revenue
    FROM orders
    GROUP BY 1, 2
)
SELECT
    month,
    product_id,
    revenue,
    RANK() OVER (PARTITION BY month ORDER BY revenue DESC)       AS revenue_rank,
    SUM(revenue) OVER (PARTITION BY product_id ORDER BY month)   AS running_total,
    AVG(revenue) OVER (
        PARTITION BY product_id
        ORDER BY month
        ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
    )                                                            AS moving_avg_3m
FROM monthly_sales;
```

</details>

<details>
<summary><b>Cohort retention</b></summary>

```sql
WITH first_order AS (
    SELECT customer_id,
           DATE_TRUNC('month', MIN(order_date)) AS cohort_month
    FROM orders
    GROUP BY customer_id
),
activity AS (
    SELECT DISTINCT
        o.customer_id,
        f.cohort_month,
        (EXTRACT(YEAR  FROM o.order_date) - EXTRACT(YEAR  FROM f.cohort_month)) * 12
      + (EXTRACT(MONTH FROM o.order_date) - EXTRACT(MONTH FROM f.cohort_month)) AS month_index
    FROM orders o
    JOIN first_order f USING (customer_id)
)
SELECT
    cohort_month,
    month_index,
    COUNT(DISTINCT customer_id) AS active_customers
FROM activity
GROUP BY 1, 2
ORDER BY 1, 2;
```

</details>

<details>
<summary><b>Customer lifetime value (historical)</b></summary>

```sql
SELECT
    customer_id,
    COUNT(DISTINCT order_id)                         AS total_orders,
    SUM(revenue)                                     AS lifetime_revenue,
    SUM(revenue) / NULLIF(COUNT(DISTINCT order_id),0) AS avg_order_value,
    MIN(order_date)                                  AS first_order,
    MAX(order_date)                                  AS last_order
FROM orders
GROUP BY customer_id;
```

</details>

**Query optimization practices:** filtering early, selecting only required columns, indexing join and filter keys, reading execution plans (`EXPLAIN ANALYZE`), and replacing repeated subqueries with CTEs or materialized steps.
